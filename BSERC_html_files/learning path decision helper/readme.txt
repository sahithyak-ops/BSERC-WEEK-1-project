## Project 2: Learning Path Decision Helper

A small interactive tool that helps students decide what to learn next based on their interests, current experience, goals and available time.

### Features
- Six learning tracks to choose from.
- Beginner, some-basics and intermediate experience levels.
- Different learning goals and a daily study-time slider.
- Generates a suggested learning roadmap with stages and mini-projects.
- Allows users to mark stages as completed.
- Saves the learning plan in the browser.
- Includes a learning guide with practical study tips.
- Responsive layout for laptop and mobile screens.
- Print option to save the roadmap as a PDF.

### Technologies Used
- HTML
- CSS
- JavaScript
- Browser localStorage

### How to Run
1. Open `learning_path_decision_helper.html` in a web browser.
2. Select a learning interest and fill in the preferences.
3. Click "Build my learning path".
4. Explore the roadmap, mark completed stages and save the plan.

### Notes
The tool uses predefined learning paths and does not require a backend or API. Saved progress is stored locally in the browser.
