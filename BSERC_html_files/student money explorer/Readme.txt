## Project 3: Student Money Explorer

MoneyMap is a student budgeting tool that helps users record expenses, manage a monthly budget and track a savings goal.

### Features
- Add and delete expenses.
- Categorise spending into food, transport, education, shopping and other categories.
- Set a monthly budget and view the remaining balance.
- View a category-wise spending breakdown.
- Set a savings target and track progress.
- Filter and sort expenses.
- Switch between months to review spending.
- Export monthly expenses as a CSV file.
- Save expense records and settings in the browser.
- Responsive layout for laptop and mobile screens.

### Technologies Used
- HTML
- CSS
- JavaScript
- Browser localStorage
- CSV export using JavaScript

### How to Run
1. Open `student_money_explorer.html` in a web browser.
2. Set your monthly budget.
3. Add expenses with their amounts, categories and dates.
4. Explore the spending breakdown and savings goal.
5. Use the filters or export your expenses as a CSV file.

### Notes
The application works without a backend or external API. Data is stored in the current browser, so it may not appear in another browser or on another device. The budgeting insights are based on the data entered by the user.
