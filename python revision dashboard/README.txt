
PYREVISE - PYTHON REVISION DASHBOARD
===================================

ABOUT THE PROJECT
-----------------
PyRevise is a simple dashboard I made to help students revise Python
concepts in one place. Instead of going through separate notes every
time, users can explore topics, test themselves with quizzes and use
flashcards for quick revision.

FEATURES
--------
1. Overview page with revision progress and a daily checklist.
2. Python topic notes with code examples.
3. Search and filter options for finding topics.
4. Practice quiz with multiple-choice questions, feedback and scores.
5. Flashcards with answers, shuffle and known-card tracking.
6. Light and dark mode.
7. Progress saved in the browser using local storage.
8. Responsive layout for laptops and smaller screens.

TECHNOLOGIES USED
-----------------
- HTML for the page structure
- CSS for styling and responsive layout
- JavaScript for interactions and functionality
- Browser local storage to save progress

HOW TO RUN
----------
1. Keep all three project files in the same folder:
   - python_revision_dashboard.html
   - styles.css
   - app.js

2. Open python_revision_dashboard.html in a web browser.

3. Use the sidebar to move between the Overview, Python Topics,
   Practice Quiz and Flashcards sections.

No additional installation is required.

PROJECT FILES
-------------
python_revision_dashboard.html - Main dashboard page
styles.css                     - Styling and layout
app.js                         - Interactive features and logic

NOTE
----
This is a front-end learning project. Progress is stored locally
in the browser, so it is not shared automatically between different
browsers or devices.

The project is intended for Python revision and practice. The quiz
questions and notes are basic learning material and can be expanded
with more topics in the future.
